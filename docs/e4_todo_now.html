입력은 캐시 슬라이스 (1, Hkv, n, d) bf16. float32로 올려 계산하고 bf16으로 되돌린다. 함수 셋 다 axis 하나로 키·값을 가른다.

함수쓰는 곳규칙
fq_nvfp4(x, axis)R·E (4비트), 균일 4비트 대조군그룹 16 최대값으로 스케일 → |y| ≤ 6 → E2M1 격자 {0, .5, 1, 1.5, 2, 3, 4, 6}에 가장 가까운 값(경계 .25 .75 1.25 1.75 2.5 3.5 5, torch.bucketize)
fq_ternary(x, axis)T (2비트)그룹별 s = mean|x| → q = sign(x)·[|x| > 0.5 s] → q·s
fq_kivi2(x, axis)KIVI식 2비트 대조군그룹별 비대칭 균등: scale = (max−min)/3, q = round((x−min)/scale) ∈ 0..3
  • 축 규칙(확정 4a): 키는 axis=-2(토큰 16개 묶음, 채널마다 스케일), 값은 axis=-1(채널 16개 묶음, 토큰마다 스케일). x.unflatten(axis, (-1, 16))으로 묶으면 한 코드로 둘 다 된다.
  • 스케일은 E4M3(확정 5b): s.to(torch.float8_e4m3fn).float(). 최소 서브노멀이 약 0.002라 작은 그룹이 0이 되므로 NVFP4처럼 텐서당 fp32 스케일 한 단계를 더 둔다: glob = x.abs().amax()/(6·448), s = e4m3(g_abs/6/glob)·glob. ternary의 s도 같은 2단계.
if __name__ == "__main__":            # 자기 검사
    x = torch.randn(1, 8, 16, 128)
    for f, lim in ((fq_nvfp4, .15), (fq_ternary, .8), (fq_kivi2, .5)):
        for ax in (-2, -1):
            y = f(x, ax); assert y.shape == x.shape
            assert ((y - x).norm() / x.norm()) < lim, (f.__name__, ax)
        assert not torch.equal(f(x, -2), f(x, -1))   # 스케일 축이 실제로 다른가
    print("quant ok")

select_representatives(keys, K): keys (Hkv, n, d)를 받아 남길 토큰 인덱스 K개를 정렬해 돌려준다.

  • 헤드마다 다른 토큰을 고르면 캐시가 울퉁불퉁해져 못 담는다. 토큰을 헤드 연결 벡터 (n, Hkv·d) float32로 보고 레이어당 집합 하나를 고른다.
  • 초기 중심 = linspace(0, n−1, K) 위치의 토큰(결정적). torch.cdist → argmin → 군집 평균, 10회.
  • 대표 = 군집마다 중심에 가장 가까운 실제 토큰(확정 8a). 빈 군집이면 아직 안 뽑힌 토큰 중 자기 중심에서 가장 먼 것으로 채워 정확히 K개.
  • RoPE 재회전 없음. 값은 같은 인덱스로 자른다.
idx = select_representatives(torch.randn(8, 128, 128), 64)
assert idx.numel() == 64 and idx.unique().numel() == 64 and (idx[1:] > idx[:-1]).all()
assert select_representatives(torch.randn(8, 16, 128), 16).numel() == 16   # K == n 이면 전부
끝 판정위 assert 통과. 128 → 64가 A100에서 수 ms(루프 10회, cdist 한 번씩).

kvpress.presses.base_press.BasePress를 상속하고 forward_hook을 통째로 덮어쓴다(DecodingPress가 하는 방식). 프리필에서는 prompt_len만 적고 아무것도 하지 않는다.

  • 어텐션 함수: collect_calibration.py의 attn을 복사하고 측정을 module.layer_idx == MEASURE_LAYER and query.shape[2] == 1로 제한. 채널은 win256_mid@max1 하나: 칸 [max(4, g−255), g−8](g = n−1)의 키만 잘라 max-pool → softmax → 그룹 평균 → 1% 미만 비율. 결과는 모듈 전역 PHI 리스트에, reset()이 비우고 MEASURE_LAYER = self.layer를 써 넣는다.
  • 상태 기계: 구간 표는 하나([{type, level, len, closed}]). 스텝마다 레이어 0의 훅이 plan_step으로 action 목록을 만들고, 모든 레이어가 apply_step으로 같은 목록을 실행한다. 마지막 레이어가 쓰고 지운다.
  • plan_step 순서: ① 기존 구간 길이 스냅샷·시작 칸 계산 → ② 구간 경계면 앞 구간 닫기, 닫힌 것이 T면 그 앞 구간 전부 한 단계(경우 1) → ③ 이번 토큰을 열린 구간에 +1 → ④ 열린 구간 길이가 16의 배수면 ("quant", kind, 16) → ⑤ total > k인 동안 닫힌 구간 중 T→E→R 순으로 가장 오래된 것을 한 단계(경우 2), 전부 4토큰이면 중단 → ⑥ 바뀐 구간마다 ("evict", start, old_len, new_len). 좌표는 전부 ①의 스냅샷 기준.
  • apply_step: quant는 K[..., -16:, :]/V[..., -16:, :]에 제자리 대입(키 axis −2, 값 axis −1). evict는 keep 마스크 하나를 만들어 layer.keys = K[:, :, keep], 값도 같이.
  • 불변식(레이어 0, 매 스텝 assert): sum(len) == layer.keys.shape[2] − prompt_len.
  • 필드: theta, layer=24, tau=128, group=16, budget=1024|None, quant="tbq"|"nvfp4_all"|"kivi2"|None, labels="sparsity"|"random"|"periodic", retain=(64,32,16,8,4), seed. __call__은 super().__call__ 뒤에 reset().

  1. 매 스텝 불변식 통과, log["cache_len"]이 96+16 안에서 톱니 모양.
  2. labels="periodic"으로 T가 나오게 해 경우 1이 실제로 발화하는지(앞 구간들의 level이 한꺼번에 오름).

  4. thinkv 설정이 EOS까지 끝나고 텍스트가 깨지지 않음. 깨지면 확정 14의 메모대로 R을 FP8로 올리는 실험을 추가.
  5. DecodingPress(SnapKVPress(window_size=64), compression_interval=128, target_size=1024)도 EOS까지 돌려 cache_len ≤ 1024+128. 0단계가 증명한 것은 Knorm뿐이다.
