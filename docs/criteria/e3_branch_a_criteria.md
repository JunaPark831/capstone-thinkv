# E3 분기점 A 사전 판정 기준

- 작성 시각: 2026-10-07 15:52 KST
- 상태: P=10 희소도 수집은 시작됐지만 KDE 분석, 층별 분포, 봉우리 수 및 3봉 비율은 확인하지 않은 상태에서 작성했다.
- 목적: 결과를 확인한 뒤 성공 기준을 조정하는 것을 방지하고, 1.5B 모델에서 희소도 3봉 가정이 유지되는지 사전에 고정한 규칙으로 판정한다.

## 데이터 및 생성 조건

- 데이터셋: `simplescaling/s1K-1.1`의 `train` split
- 선택: `cot_type == "math"`인 877문제를 남기고 `shuffle(seed=0)`한 뒤 앞의 10문제(P=10)
- 모델: `deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B`
- 샘플링: seed 0, temperature 0.6, top-p 0.95
- 최대 생성 길이: 4096토큰
- 희소도: 디코딩 스텝의 각 층에서, 헤드별 어텐션 최댓값의 1% 미만인 위치가 전체 헤드·KV 위치에서 차지하는 비율

## KDE 및 봉우리 탐지

각 프롬프트와 각 레이어의 스텝별 희소도 배열에 독립적으로 KDE를 적용한다.

- 평가 구간: `[0, 1]`
- 평가 격자: 512개 점
- 기준 bandwidth: SciPy `gaussian_kde`의 Scott factor
- 비교 bandwidth: Scott factor ×0.5, ×1, ×2
- KDE 밀도는 각 곡선의 최댓값으로 나누어 정규화한다.
- 봉우리는 `scipy.signal.find_peaks`로 찾는다.
- prominence: 0.05
- 탐지된 봉우리가 정확히 3개일 때만 해당 프롬프트·레이어를 3봉으로 판정한다.

`bw_method=0.5`를 Scott ×0.5로 간주하지 않는다. 각 희소도 배열에서 Scott factor를 먼저 구한 뒤 0.5, 1, 2를 곱한다.

## 분기점 A 통과 기준

1. bandwidth 조건별로 각 레이어에서 정확히 3봉인 프롬프트의 비율을 계산한다.
2. 동일한 레이어가 Scott ×0.5, ×1, ×2의 세 조건 모두에서 3봉 비율 50% 이상이어야 한다. P=10이므로 각 조건에서 최소 5개 프롬프트가 정확히 3봉이어야 한다.
3. 위 조건을 만족하는 동일한 레이어가 4개 이상이면 분기점 A를 **통과**한다.
4. 만족하는 레이어가 4개 미만이면 분기점 A를 **통과하지 못한 것**으로 판정한다.

세 bandwidth에서 각각 서로 다른 레이어가 4개 이상인 것만으로는 통과로 보지 않는다. 세 조건에서 공통으로 기준을 만족하는 레이어가 4개 이상이어야 한다.
